Each class has its own page, where you invite students, give them Quests and follow their progress. In the sidebar, your classes are listed under **TRIBES**.

## Create a class from the sidebar

1. In the sidebar, under **TRIBES**, select **+**, then **Create a group**.

![The + button under TRIBES, with Create a group and Join a group](/docs/teaching/create-a-class-1-tribes-menu.png)

2. If you teach at more than one school, choose the school under **Choose school:**, then select **Next**.
3. Type the class name where it says **Enter name ...**, and a short description below it.
4. Pick a color under **Featured**.
5. Select **Create**. Your new class opens.

![The Create class page, with the name Grade 8 Coding, a description and a light blue color picked](/docs/teaching/create-a-class-2-create-class-page.png)

Next, [invite your students](/docs/teaching/invite-students-to-your-class).

## Create a class in the dashboard

Admins can also create classes in the dashboard, which they open from their account menu with **Manager Account**.

1. In the sidebar, select **Classes**, then **Add Class**.

![The Add Class button on the Classes page](/docs/teaching/create-a-class-3-add-class-button.png)

2. Type a **Class name** and a **Class description**. Both are required.
3. Optionally, pick a **Cover** color and upload a photo. If you leave them empty, CodeTribe picks them for you.
4. Select **Save**. The class shows in the list.

![The Add Class box, with the class name Grade 7 Coding, a description and a cover color](/docs/teaching/create-a-class-4-add-class-dialog.png)
